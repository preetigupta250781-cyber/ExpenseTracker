# Money Maker 🚀

A premium, offline-first personal finance tracker built with React Native and Expo. Designed with a sleek, minimalist monochrome dark mode, Money Maker provides blazing-fast transaction tracking, custom animated SVG analytics, and interactive physics-based savings goals.

## ✨ Features

- 💎 **Premium Monochrome UI:** A true-black, minimalist design language inspired by high-end fintech applications.
- ⚡ **Offline-First Architecture:** Powered by `expo-sqlite` for instant, zero-latency reads and writes. Your financial data never leaves your device.
- 📊 **Custom SVG Analytics:** Smooth, cubic-bezier line charts and animated category progress bars built from scratch—no heavy charting libraries.
- 🎯 **Interactive Savings Goals:** Track your savings with highly optimized, physics-based Jar animations powered by React Native Reanimated.
- 📄 **PDF Reporting:** Generate and share beautiful monthly expense reports instantly.
- 📱 **Fully Responsive:** Smart typography scaling and bento-grid layouts that look great on any device size.

## 🛠 Tech Stack

- **Framework:** React Native / Expo (Router)
- **Styling:** NativeWind v4 (Tailwind CSS)
- **Animations:** React Native Reanimated 3
- **Graphics:** React Native SVG
- **Database:** Expo SQLite (Next-Gen Synchronous API)
- **Icons:** Expo Vector Icons (Ionicons)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed, and the [Expo Go](https://expo.dev/client) app installed on your iOS or Android device.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/money-maker.git
   cd money-maker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Expo development server:
   ```bash
   npx expo start -c
   ```

4. Scan the QR code with your phone's camera (iOS) or the Expo Go app (Android) to launch the app!
